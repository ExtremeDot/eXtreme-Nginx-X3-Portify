📖 راهنمای کاربری و مراحل استفاده از سیستم
  • گام اول (دریافت اطلاعات از پنل سنایی): وارد پنل ثنایی (Sui / 3X-UI) خود شوید. از منوی سمت چپ به بخش Overview (صفحه اول) بروید. از منوی بالای چارت‌ها گزینه Manage و سپس Config را انتخاب کنید. محتوای فایل config.json را به طور کامل کپی کرده و در کادر متنی بالا پیست کنید یا فایل را مستقیماً آپلود کنید؛ سپس دکمه پردازش را بزنید.
  • 🔒 اطلاعیه امنیت و حریم خصوصی: این ابزار به صورت ۱۰۰٪ کلاینت‌ساید (کدهای لوکال فرانت‌اند) اجرا می‌شود. هیچ دیتایی، آدرس دامین یا کدهای کانفیگی به هیچ سرور خارجی ارسال یا ذخیره نمی‌شود و تمامی عملیات‌ها درون مرورگر شما انجام می‌گیرد.
  • گام دوم (پیکربندی شبکه دامین‌ها): آدرس‌های دامین مستقیم و دامین CDN خود را وارد کنید. اسکریپت به صورت هوشمند مسیرهای سرتیفیکیت SSL هر بخش را تفکیک می‌کند. همچنین آدرس سایت استتار (Fake Site) را مشخص کنید.
  • گام سوم (تنظیمات سرور لینوکس Nginx): پس از زدن دکمه تولید نهایی و دریافت خروجی متنی، وارد سرور خود شده و دستورات زیر را برای نصب و راه‌اندازی اعمال کنید:
    # ۱. بروزرسانی پکیج‌ها و نصب وب‌سرور انجین‌اکس
    sudo apt update && sudo apt install nginx -y

    # ۲. ایجاد و ویرایش فایل کانفیگ جدید برای لوکیشن‌ها
    nano /etc/nginx/conf.d/v2ray.conf

    # [کدهای تولید شده توسط سایت را داخل این فایل پیست کرده و با Ctrl+O و Ctrl+X ذخیره کنید]

    # ۳. تست صحت ساختار کدهای پیست شده بدون خرابی سرور
    nginx -t

    # ۴. اعمال نهایی تغییرات با ری‌استارت کردن سرویس انجین‌اکس
    systemctl restart nginx
  • گام چهارم (اتمام کار): پورت‌های ورودی سرور هسته (Core) خود را به پورتی غیر از ۸۰ و ۴۴۳ تغییر دهید تا ترافیک‌های ورودی تداخل نداشته باشند و انجین‌اکس کار مانیتورینگ و یکپارچه‌سازی روی یک پورت واحد را به درستی به سرانجام برساند.

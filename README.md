یک ابزار کلاینت‌ساید و فوق‌العاده سبک برای تجمیع تمامی کانفیگ‌ها و پروتکل‌های پنل **3X-UI** روی **یک پورت واحد (مانند 80 یا 443)** با استفاده از وب‌سرور قدرتمند Nginx. این سیستم دامین مستقیم، دامین پشت CDN و سایت استتار (Fake Site) شما را به صورت خط به خط تفکیک کرده و گواهی‌های SSL اختصاصی مجزایی برای هر بلاک سرور تولید می‌کند.

تمامی کانفیگ ها رو به پورت های 443 و 80 هدایت میکند


---

## ✨ قابلیت‌های برجسته

- 🌐 **تفکیک کامل دامین‌ها:** تفکیک ساختاری و کاملاً متمایز دامین مستقیم و CDN جهت جلوگیری از اشتباهات کانفیگ.
- 🔒 **حریم خصوصی و امنیت کامل:** این برنامه ۱۰۰٪ روی مرورگر شما (Client-Side) اجرا شده و هیچگونه اطلاعات، توکن یا کدهای کانفیگ شما به هیچ سروری ارسال یا در جایی ذخیره نمی‌شود.
- ⚙️ **استخراج هوشمند از پنل سنایی:** قابلیت پارس و استخراج خودکار فیلدهای پروتکل، پورت داخلی و مسیرها (Paths) از ساختار بومی `config.json`.
- 🎭 **پشتیبانی از سایت استتار (Camouflage):** هدایت خودکار ترافیک‌های متفرقه و اسکنرها به سایت فیک انتخاب شده بدون افت امنیت.
- 💾 **دانلود و کپی سریع:** ذخیره مستقیم به عنوان فایل استاندارد `nginx.conf` یا کپی متنی در کلیپ‌بورد.

## 📖 راهنمای گام‌به‌گام کار با ابزار و راه‌اندازی

### گام ۱: استخراج کدهای پنل سنایی (Sui / 3X-UI)
1. وارد محیط وب پنل سنایی خود شوید.
2. از منوی سمت چپ وارد بخش **Overview** (صفحه اول) شوید.
3. در منوی بالای جدول‌ها و چارت‌ها، روی گزینه **Manage** کلیک کرده و وارد بخش **Config** شوید.
4. محتویات فایل متنی نمایش داده شده به نام `config.json` را به طور کامل کپی کرده و در کادر اول ابزار پیست کنید یا فایل را آپلود کنید و دکمه **پردازش خودکار** را بزنید تا مسیرها و پورت‌ها به صورت خودکار استخراج شوند.

### گام ۲: مشخص کردن دامین‌ها و سایت فیک
1. آدرس دامین مستقیم و دامین پشت CDN خود را وارد کنید (مسیرهای سرتیفیکیت‌ها به صورت اتوماتیک تفکیک خواهند شد).
2. آدرس یک سایت معتبر (مانند `https://www.wikipedia.org`) را به عنوان سایت پنهان‌سازی وارد کنید.
3. روی دکمه **تولید فایل نهایی کانفیگ دو دامین Nginx** کلیک کنید.

### گام ۳: راه‌اندازی و اجرای دستورات در سرور لینوکس
وارد ترمینال سرور خود (SSH) شوید و دستورات زیر را خط به خط اجرا کنید:

```bash
# ۱. بروزرسانی مخازن سیستم‌عامل و نصب وب‌سرور انجین‌اکس با تایید خودکار
sudo apt update && sudo apt install nginx -y

# ۲. ایجاد و ویرایش فایل کانفیگ جدید انجین‌اکس به کمک ادیتور نانو
nano /etc/nginx/conf.d/v2ray.conf
# [کدهایی که ابزار به شما خروجی داده است را در این بخش پیست کنید. سپس با کلیدهای Ctrl+O ذخیره و با Ctrl+X خارج شوید]

# ۳. بررسی و صحت‌سنجی کدهای پیست شده برای اطمینان از عدم وجود خطای نگارشی
nginx -t

# ۴. اعمال نهایی تغییرات و لود مجدد کانفیگ‌ها با ری‌استارت کردن سرویس انجین‌اکس
systemctl restart nginx
